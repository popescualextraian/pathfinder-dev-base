# SSH into the dev container Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `agentic dev ssh KEY.pub` plus `agentic dev recreate` give a key-only SSH login as `dev` into the
dev container on `127.0.0.1:${AGENTIC_SSH_PORT:-2222}`, for editors that connect over SSH.

**Architecture:** The host CLI only writes the keys file, adds two mounts and one port to `dev_start`, and
reports the port. Inside the image, a start step generates the host key once, writes the sshd config and
starts a non-root sshd. A profile snippet gives SSH shells the container environment from PID 1.

**Tech Stack:** bash, bats, Docker, OpenSSH 9.6 (Ubuntu package).

**Spec:** `docs/specs/2026-11-10-dev-ssh-design.md` (D1–D7 below refer to its decisions).

## Global Constraints

- Work on a branch `dev-ssh`; push nothing. No `Co-Authored-By` or attribution lines in commits.
- bash: `set -euo pipefail` in the CLI, `set -uo pipefail` in start steps (like `06-task-home.sh`), short
  comments, `shellcheck -x` clean. Every behaviour gets a bats test written first.
- Container paths: keys `/etc/agentic/ssh/authorized_keys` (ro), host key dir `/home/dev/.sshd` (rw).
- Host paths: `$AGENTIC_DATA/projects/<project>/ssh/keys/authorized_keys` (600, dir 700) and
  `$AGENTIC_DATA/projects/<project>/ssh/host/`.
- Container port 2222 always; host port `AGENTIC_SSH_PORT` from `.agentic/.env`, default 2222, bound to `127.0.0.1`.
- No secret in an image layer, `~/.agentic/env` or a log; the package's `/etc/ssh/ssh_host_*` are removed at build.
- No company names, hosts or URLs in code, tests or docs (`tools/leak-check.sh`).

## Review Focus

- **Only shell, setup, doctor or a task container start:** the keys are never mounted there, so the step
  must exit 0 silently. Pinned in Task 2 (skip test) and Task 4 (`shell` gets no ssh mount).
- **A `.pub` file with CRLF line endings or a trailing comment** (Windows-generated key read through `/mnt/c`):
  it must be accepted and stored without `\r`. Pinned in Task 4.
- **The host user's uid is not 1000:** login must still work (`StrictModes no`). Pinned by the config-line
  test in Task 2; the smoke test covers login itself.
- **`PATH` in an SSH session:** without the import the image's tools (java, node, claude) are missing.
  Pinned in Task 3.
- **Port 2222 already taken by another project's dev container:** start fails with a message that names
  the port and `AGENTIC_SSH_PORT`. Pinned in Task 4.

@test "sshd starts with that config and its log in the start state" {

  grep -qx -- "-f $AGENTIC_STATE/sshd_config -E $AGENTIC_STATE/sshd.log" "$BATS_TEST_TMPDIR/sshd.log"

@test "--check writes and starts nothing" { run bash "$S" --check; [ "$status" -eq 0 ]; [ ! -e "$AGENTIC_STATE/sshd_config" ]; }

### Task 3: SSH sessions get the container environment

**Files:**
- Modify: `image/profile.d/agentic.sh` (append)
- Test: `tests/bats/ssh-env.bats` (new)

**Interfaces:**
- Produces: function `agentic_ssh_env FILE` (FILE: NUL-separated `K=V` entries), called at the end of the file
  as `[ -z "${SSH_CONNECTION:-}" ] || agentic_ssh_env "${AGENTIC_PID1_ENVIRON:-/proc/1/environ}"`.

- [ ] **Step 1: Write the failing tests.** A helper writes `$BATS_TEST_TMPDIR/environ` with
  `printf '%s\0' PATH=/opt/tool/bin:/usr/bin X=from-pid1 HOME=/root TERM=dumb HOSTNAME=c SHLVL=0 PWD=/ Y='a b' KEEP=pid1`.
  Each test runs `bash -c 'export KEEP=mine HOME=/home/me TERM=xterm; source "$P"; echo "$PATH|$X|$Y|$HOME|$TERM|$KEEP"'`.

```bash
@test "with SSH_CONNECTION the PID 1 environment is exported, PATH included" {
  SSH_CONNECTION="1 2 3 4" AGENTIC_PID1_ENVIRON="$BATS_TEST_TMPDIR/environ" run bash -c "$cmd"
  [ "$output" = "/opt/tool/bin:/usr/bin|from-pid1|a b|/home/me|xterm|mine" ]
}
@test "without SSH_CONNECTION nothing is imported" {
  AGENTIC_PID1_ENVIRON="$BATS_TEST_TMPDIR/environ" run bash -c "$cmd"
  [[ "$output" != *from-pid1* ]]
}
@test "an unreadable environ file is silent and changes nothing" {
  SSH_CONNECTION="1 2 3 4" AGENTIC_PID1_ENVIRON=/nonexistent run bash -c "$cmd"
  [ "$status" -eq 0 ] && [[ "$output" != *from-pid1* ]] && [ -z "$(bash -c "$cmd" 2>&1 >/dev/null)" ]
}
@test "sourcing it twice under set -u is harmless" {
  SSH_CONNECTION="1 2 3 4" AGENTIC_PID1_ENVIRON="$BATS_TEST_TMPDIR/environ" run bash -uc 'source "$P"; source "$P"; echo "$X"'
  [ "$output" = from-pid1 ]
}
```

- [ ] **Step 2: Run:** `bats tests/bats/ssh-env.bats` — expected: FAIL.
- [ ] **Step 3: Implement `agentic_ssh_env`:** `while IFS= read -r -d '' kv` over the file (`2>/dev/null`, return 0
  if unreadable); skip `HOME HOSTNAME PWD SHLVL TERM`; export `PATH` always; export any other key only when
  `[ -z "${!k+x}" ]`. Values are never `eval`ed (a value may hold `$(...)`; add a test entry `Z='$(touch pwned)'`
  and assert the file is not created).
- [ ] **Step 4: Run:** `bats tests/bats/ssh-env.bats tests/bats/build-helpers.bats && shellcheck image/profile.d/agentic.sh` — expected: PASS.

```bash
@test "dev without allowed keys adds no ssh mount and no ssh port" {
  run ag dev; run1="$(docker_sub run)"
  [[ "$run1" != *"/etc/agentic/ssh"* && "$run1" != *":2222"* ]]
}
@test "dev with allowed keys mounts the keys read-only, the host key dir, and publishes 2222 on loopback" {
  mkdir -p "$AGENTIC_DATA/projects/demo/ssh/keys"; echo "ssh-ed25519 AAAA k" > "$AGENTIC_DATA/projects/demo/ssh/keys/authorized_keys"
  run ag dev; run1="$(docker_sub run)"
  grep -qx "$AGENTIC_DATA/projects/demo/ssh/keys:/etc/agentic/ssh:ro" <<<"$run1"
  grep -qx "$AGENTIC_DATA/projects/demo/ssh/host:/home/dev/.sshd" <<<"$run1"
  grep -qx "127.0.0.1:2222:2222" <<<"$run1"
}
@test "AGENTIC_SSH_PORT in .agentic/.env picks the host port; a bad one is refused" {  # keys as above
  echo AGENTIC_SSH_PORT=2233 > "$PROJ/.agentic/.env"; run ag dev; grep -qx "127.0.0.1:2233:2222" <<<"$(docker_sub run)"
  echo AGENTIC_SSH_PORT=99999 > "$PROJ/.agentic/.env"; run ag dev; [ "$status" -ne 0 ]; [[ "$output" == *AGENTIC_SSH_PORT* ]]
}
@test "a failed start with ssh on names the ssh port and AGENTIC_SSH_PORT" {  # keys as above
  DOCKER_RUN_RC=1 run ag dev; [[ "$output" == *2222* && "$output" == *AGENTIC_SSH_PORT* ]]
}
@test "shell gets no ssh mount even with allowed keys" {  # keys as above
  run ag shell true; [[ "$(docker_sub run)" != *"/etc/agentic/ssh"* ]]
}
@test "dev ssh adds a public key once, with modes 700/600, and prints the block" {
  printf 'ssh-ed25519 AAAAC3 me@laptop\r\n' > "$BATS_TEST_TMPDIR/k.pub"
  run ag dev ssh "$BATS_TEST_TMPDIR/k.pub"; [ "$status" -eq 0 ]; run ag dev ssh "$BATS_TEST_TMPDIR/k.pub"
  f="$AGENTIC_DATA/projects/demo/ssh/keys/authorized_keys"
  [ "$(cat "$f")" = "ssh-ed25519 AAAAC3 me@laptop" ]
  [ "$(stat -c %a "$f")" = 600 ] && [ "$(stat -c %a "${f%/*}")" = 700 ]
  [[ "$output" == *"Host agentic-demo"* && "$output" == *"Port 2222"* && "$output" == *"User dev"* ]]
}
@test "dev ssh refuses a private key and a file that is not a key" {
  printf -- '-----BEGIN OPENSSH PRIVATE KEY-----\nx\n' > "$BATS_TEST_TMPDIR/k"
  run ag dev ssh "$BATS_TEST_TMPDIR/k"; [ "$status" -ne 0 ]; [[ "$output" == *"pass the .pub file"* ]]
  echo hello > "$BATS_TEST_TMPDIR/x"; run ag dev ssh "$BATS_TEST_TMPDIR/x"; [ "$status" -ne 0 ]
  [ ! -e "$AGENTIC_DATA/projects/demo/ssh/keys/authorized_keys" ]
}
@test "dev ssh says to recreate when the running container does not publish the port" {  # keys as above
  DOCKER_RUNNING=true run ag dev ssh; [[ "$output" == *"run agentic dev recreate"* ]]
}
@test "dev status shows the ssh address when the port is published" {
  DOCKER_RUNNING=true DOCKER_PORT=127.0.0.1:2222 run ag dev status; [[ "$output" == *"ssh=127.0.0.1:2222"* ]]
}
```

  Accepted first fields: `ssh-ed25519`, `ssh-rsa`, `ecdsa-sha2-*`, `sk-*`. Lines are stripped of `\r`; blank
  lines skipped; any other line refuses the whole file, nothing written.
