# Revamp Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Turn `agentic.yaml` into a short file whose `setup:` list holds our own one-line commands
(`add plugin`, `add mcp`, `copy`, `mount`, `volume`, `add workspace`, ...), applied at build, start or
run, and remove the per-technology code (git, AWS, Atlassian, Graphify, models, certs, plugins).

**Architecture:** One bash parser (`image/lib/setup-line.sh`) understands a line. The host CLI edits
the file through `agentic-setup-edit` in a throwaway container. `render-dockerfile.sh` turns
build-phase lines into one `RUN agentic-apply '<line>'` each; `agentic-apply` runs the harness CLIs
against a seed home under `/opt/agentic/seed`. At start, `40-seed` links plugin folders and 3-way
merges the seed's JSON into the mounted harness home, `60-assets` copies skills, agents, commands
and instructions, and `15-workspaces` clones workspaces. Run-phase lines travel as an image label
that the host turns into `-v` arguments.

**Tech Stack:** bash 5, jq, yq v4, python3 (only `shlex` for splitting a line), bats, Docker,
Claude Code CLI 2.1.x, Copilot CLI 1.0.x.

**Spec:** `docs/specs/2026-10-14-revamp-design.md` (read it first; section numbers below refer to it).

## Global Constraints

- No company resources: no certificates, company names, hosts, URLs or product-specific integrations. Examples use `example.com`. `make lint` runs `tools/leak-check.sh`.
- No secret in an image layer, `~/.claude.json`, `~/.agentic/env` or a log. MCP env values from `--env KEY` are written as the literal text `${KEY}`.
- bash: `set -euo pipefail` in executables (`set -uo pipefail` in start steps, as today), short comments, shellcheck-clean, a bats test for every behaviour, written first.
- No `Co-Authored-By` or other attribution lines in commits. Do not push.
- Every task ends with its own bats file green and `make lint` clean; the full `make test` runs at the end of each stage. Slow and live checks are grouped, not run per task: the live harness measurements once (Task 1), `make build` at the end of Stage 2 (Task 7) and Stage 3 (Task 10), `make smoke` in Task 16 and Task 18, the remote VM check once in Task 18.
- Start steps: exit 0 ok, 1 fatal, 2 warning; every step supports `--check` and writes nothing then.
- `agentic.yaml` `version: 2` only; `version: 1` is refused with `re-run agentic init` (no converter).
- One container belongs to one user (R13); tasks get `mount` and `volume` lines like dev containers.
- `copy` of a secret-looking file (`.env`, `id_*`, `*.pem`, `*.key`, `credentials`) is done, with a warning; no `--force`.

## Review Focus

1. A setup line containing quotes, spaces, `~`, `$` or `*`: it must be stored and replayed literally, never expanded by a shell (Task 2 test "words stay literal").
2. A user who deletes a `setup` line and rebuilds: what that line added must disappear from the mounted harness home, while keys the user added by hand stay (Task 8 tests "removed line" and "user key kept").
3. `agentic mount ~/.gitconfig ...` typed in a shell, where bash already expanded `~`: the committed line must say `~/.gitconfig`, not `/home/<user>/.gitconfig` (Task 12 test "home path written as ~").
4. A harness home that already has a real `installed-plugins/` or `plugins/` folder from before the revamp: moved aside once, not deleted, and linked (Task 8 test "real folder moved aside").
5. Removing an asset or workspace: the clone is never deleted; asset files the step installed earlier are removed only inside the harness home (Task 9 test "only removes inside the home", Task 12 test "remove workspace keeps clone").

- [ ] **Step 3: Implement `image/lib/setup-line.sh`**

```bash
#!/usr/bin/env bash
# setup: lines (docs/specs/2026-10-14-revamp-design.md section 4): splitting, parsing, validation.
# Source after common.sh. Nothing here runs a line; it only reads it.

SECRET_LIKE='(^|/)(\.env(\..*)?|id_[A-Za-z0-9]+|credentials|[^/]*\.pem|[^/]*\.key)$'

# line_words LINE: LINE split as a shell would, without expanding anything, into the array WORDS.
line_words() {
  local enc
  # python prints the words NUL-joined and base64-encoded, so no pipe can hide its failure
  enc="$(python3 -I -c '
import base64, shlex, sys
try:
    words = shlex.split(sys.argv[1])
except ValueError as e:
    sys.exit(str(e))
print(base64.b64encode(b"".join(w.encode() + b"\0" for w in words)).decode())' "$1")" || return 1
  mapfile -d '' -t WORDS < <(base64 -d <<<"$enc")
}

_rel_ok() { [ -n "$1" ] && [[ "$1" != /* ]] && [[ "/$1/" != */../* ]]; }
_abs_ok() { [[ "$1" == /* ]] && [[ "$1/" != */../* ]] && [[ "$1" != *[:,]* ]]; }
_fail() { L_ERR="$1"; return 1; }

# norm_targets T: the targets in a fixed order, comma-joined; fails on an unknown one.
norm_targets() {
  local t x out=() c=0 p=0
  IFS=, read -ra t <<<"$1"
  for x in "${t[@]}"; do
    case "$x" in claude) c=1 ;; copilot) p=1 ;; *) return 1 ;; esac
  done
  [ "$c" = 1 ] && out+=(claude)
  [ "$p" = 1 ] && out+=(copilot)
  [ "${#out[@]}" -gt 0 ] || return 1
  (IFS=,; echo "${out[*]}")
}

# parse_line LINE: see the Interfaces of Task 2 in docs/plans/2026-10-14-revamp.md.
parse_line() {
  L_KIND=""; L_PHASE=""; L_KEY=""; L_TARGETS=""; L_SRC=""; L_DEST=""; L_OPT=""; L_REF=""
  L_TRANSPORT=""; L_URL=""; L_ENV=(); L_CMD=(); L_ERR=""; L_WARN=""
  [[ "$1" != *$'\n'* ]] || _fail "a line cannot span lines" || return 1
  line_words "$1" || _fail "unbalanced quotes" || return 1
  local w=("${WORDS[@]}") pos=() i=0 a name="" readonly=0 dashdash=0
  while [ "$i" -lt "${#w[@]}" ]; do
    a="${w[i]}"
    case "$a" in
      --) L_CMD=("${w[@]:i+1}"); dashdash=1; break ;;
      --target) i=$((i + 1)); L_TARGETS="${w[i]:-}"
                norm_targets "$L_TARGETS" >/dev/null || _fail "--target takes claude, copilot or claude,copilot" || return 1 ;;
      --env) i=$((i + 1)); L_ENV+=("${w[i]:-}") ;;
      --transport) i=$((i + 1)); L_TRANSPORT="${w[i]:-}" ;;
      --name) i=$((i + 1)); name="${w[i]:-}" ;;
      --ref) i=$((i + 1)); L_REF="${w[i]:-}" ;;
      --readonly) readonly=1 ;;
      --*) _fail "unknown option $a"; return 1 ;;
      *) pos+=("$a") ;;
    esac
    i=$((i + 1))
  done
  local cmd="${pos[0]:-}"
  if [ "$cmd" = add ]; then cmd="add ${pos[1]:-}"; pos=("${pos[@]:2}"); else pos=("${pos[@]:1}"); fi
  # which options each command takes
  local allowed
  case "$cmd" in
    "add marketplace"|"add plugin"|"add skill"|"add agent"|"add command") allowed=target ;;
    "add mcp") allowed="target env transport dashdash" ;;
    "add workspace") allowed="name ref" ;;
    mount) allowed=readonly ;;
    copy|volume) allowed="" ;;
    *) _fail "unknown command: ${w[*]:0:2}"; return 1 ;;
  esac
  [ -z "$L_TARGETS" ] || [[ " $allowed " == *" target "* ]] || _fail "--target is not an option of $cmd" || return 1
  [ "${#L_ENV[@]}" -eq 0 ] || [[ " $allowed " == *" env "* ]] || _fail "--env is not an option of $cmd" || return 1
  [ -z "$L_TRANSPORT" ] || [[ " $allowed " == *" transport "* ]] || _fail "--transport is not an option of $cmd" || return 1
  [ "$dashdash" = 0 ] || [[ " $allowed " == *" dashdash "* ]] || _fail "-- is not used by $cmd" || return 1
  [ -z "$name" ] || [[ " $allowed " == *" name "* ]] || _fail "--name is not an option of $cmd" || return 1
  [ -z "$L_REF" ] || [[ " $allowed " == *" ref "* ]] || _fail "--ref is not an option of $cmd" || return 1
  [ "$readonly" = 0 ] || [[ " $allowed " == *" readonly "* ]] || _fail "--readonly is not an option of $cmd" || return 1

  case "$cmd" in
    "add marketplace")
      [ "${#pos[@]}" -eq 1 ] || _fail "usage: add marketplace SOURCE [--target T]" || return 1
      L_KIND=marketplace; L_PHASE=build; L_KEY="${pos[0]}"; L_SRC="${pos[0]}" ;;
    "add plugin")
      [ "${#pos[@]}" -eq 1 ] && [[ "${pos[0]}" =~ ^[^@[:space:]]+@[^@[:space:]]+$ ]] \
        || _fail "usage: add plugin NAME@MARKETPLACE [--target T]" || return 1
      L_KIND=plugin; L_PHASE=build; L_KEY="${pos[0]}" ;;
    "add mcp")
      [ "${#pos[@]}" -ge 1 ] && [[ "${pos[0]}" =~ ^[A-Za-z0-9_-]+$ ]] || _fail "add mcp needs a NAME of letters, digits, _ and -" || return 1
      L_KIND=mcp; L_PHASE=build; L_KEY="${pos[0]}"
      for a in "${L_ENV[@]}"; do
        [[ "$a" =~ ^[A-Za-z_][A-Za-z0-9_]*(=.*)?$ ]] || _fail "--env takes KEY or KEY=VALUE, not '$a'" || return 1
      done
      if [ -n "$L_TRANSPORT" ]; then
        case "$L_TRANSPORT" in http|sse) ;; *) _fail "--transport takes http or sse" || return 1 ;; esac
        [ "${#pos[@]}" -eq 2 ] && [ "$dashdash" = 0 ] || _fail "usage: add mcp NAME --transport http|sse URL" || return 1
        L_URL="${pos[1]}"
      else
        [ "${#pos[@]}" -eq 1 ] && [ "${#L_CMD[@]}" -gt 0 ] || _fail "usage: add mcp NAME [--env K]... -- COMMAND [ARGS...]" || return 1
      fi ;;
    "add skill"|"add agent"|"add command")
      L_KIND="${cmd#add }"; L_PHASE=build
      [ "${#pos[@]}" -eq 1 ] || _fail "usage: add $L_KIND PATH [--target T]" || return 1
      L_KEY="${pos[0]%/}"
      _rel_ok "$L_KEY" && [[ "$L_KEY" == "${L_KIND}s/"?* ]] || _fail "$L_KIND path must be under ${L_KIND}s/ in .agentic/" || return 1 ;;
    "add workspace")
      [ "${#pos[@]}" -eq 1 ] || _fail "usage: add workspace URL|PATH [--name N] [--ref R]" || return 1
      L_KIND=workspace; L_PHASE=start; L_SRC="${pos[0]}"
      case "$L_SRC" in https://*|ssh://*|git@*:*) L_OPT=url ;; *) L_OPT=path ;; esac
      [ -z "$L_REF" ] || [ "$L_OPT" = url ] || _fail "--ref needs a URL workspace" || return 1
      if [ -z "$name" ]; then name="${L_SRC%/}"; name="${name##*[/:]}"; name="${name%.git}"; fi
      [[ "$name" =~ ^[A-Za-z0-9._-]+$ ]] && [ "$name" != . ] && [ "$name" != .. ] || _fail "workspace name '$name' is not valid; use --name" || return 1
      L_KEY="$name"; L_DEST="/workspaces/repos/$name" ;;
    copy)
      [ "${#pos[@]}" -eq 2 ] || _fail "usage: copy SRC DEST" || return 1
      L_KIND=copy; L_PHASE=build; L_SRC="${pos[0]%/}"; L_DEST="${pos[1]}"; L_KEY="$L_DEST"
      _rel_ok "$L_SRC" || _fail "copy SRC must be a path inside .agentic/" || return 1
      _abs_ok "$L_DEST" || _fail "copy DEST must be an absolute path without : or ," || return 1
      if [[ "$L_SRC" =~ $SECRET_LIKE ]]; then
        L_WARN="$L_SRC looks like a secret: it ends up in the image, readable by anyone who has it, and stays in pushed layers; use .env or mount instead"
      fi ;;
    mount)
      [ "${#pos[@]}" -eq 2 ] || _fail "usage: mount SRC DEST [--readonly]" || return 1
      L_KIND=mount; L_PHASE=run; L_SRC="${pos[0]}"; L_DEST="${pos[1]}"; L_KEY="$L_DEST"
      [ "$readonly" = 0 ] || L_OPT=ro
      [[ "$L_SRC" != *[:,]* ]] || _fail "mount SRC cannot contain : or ," || return 1
      _abs_ok "$L_DEST" || _fail "mount DEST must be an absolute path without : or ," || return 1 ;;
    volume)
      [ "${#pos[@]}" -eq 2 ] || _fail "usage: volume NAME DEST" || return 1
      L_KIND=volume; L_PHASE=run; L_KEY="${pos[0]}"; L_DEST="${pos[1]}"
      [[ "$L_KEY" =~ ^[a-z0-9][a-z0-9_.-]*$ ]] || _fail "volume NAME takes lowercase letters, digits, _ . -" || return 1
      _abs_ok "$L_DEST" || _fail "volume DEST must be an absolute path without : or ," || return 1 ;;
  esac
}

# line_ident DEFAULT_TARGETS: KIND, KEY and the effective targets of the last parsed line.
line_ident() {
  local t=""
  case "$L_KIND" in
    marketplace|plugin|mcp|skill|agent|command) t="$(norm_targets "${L_TARGETS:-$1}")" ;;
  esac
  printf '%s\t%s\t%s\n' "$L_KIND" "$L_KEY" "$t"
}

# setup_errs FILE: the errors of the resolved config's setup lines, one per line.
setup_errs() {
  local dt i=0 l id
  declare -A seen=()
  dt="$(jq -r '(.targets // ["claude","copilot"]) | join(",")' "$1")"
  while IFS= read -r l; do
    if ! parse_line "$l"; then echo ".setup[$i]: $L_ERR"
    else
      id="$(line_ident "$dt")"
      if [ -n "${seen[$id]:-}" ]; then echo ".setup[$i]: same command, key and targets as .setup[${seen[$id]}]"
      else seen[$id]="$i"; fi
    fi
    i=$((i + 1))
  done < <(jq -r '.setup // [] | .[]' "$1")
}
```

```bash
#!/usr/bin/env bash
# Reads and edits the setup: list of agentic.yaml. The host CLI runs it in a throwaway container
# (the host has no yq); /agentic-setup runs it directly. Usage:
#   agentic-setup-edit [--dir D] add LINE | remove KIND KEY [--target T] | list | run-args
set -euo pipefail
here="$(cd "$(dirname "$(readlink -f "${BASH_SOURCE[0]}")")" && pwd)"
AGENTIC_DIR="${AGENTIC_DIR:-$(cd "$here/.." && pwd)}"
# shellcheck source=../lib/common.sh
source "$AGENTIC_DIR/lib/common.sh"
# shellcheck source=../lib/config.sh
source "$AGENTIC_DIR/lib/config.sh"
dir="${AGENTIC_CONFIG_MOUNT:-/agentic-config}"
if [ "${1:-}" = --dir ]; then dir="$2"; shift 2; fi
f="$dir/agentic.yaml"
[ -f "$f" ] || { say "no agentic.yaml in $dir"; exit 1; }

lines() { yq -o=json '.setup // []' "$f" | jq -r '.[]'; }
dt="$(config_resolve "$dir" | jq -r '(.targets // ["claude","copilot"]) | join(",")')"

cmd_add() {
  local line="$1" new_id l i=0
  parse_line "$line" || { say "invalid line: $L_ERR"; exit 1; }
  [ -z "$L_WARN" ] || say "warning: $L_WARN"
  case "$L_KIND" in
    copy) [ -e "$dir/$L_SRC" ] || { say "$L_SRC is not in .agentic/"; exit 1; } ;;
    skill|agent|command)
      [ -e "$dir/$L_KEY" ] || { say "$L_KEY is not in .agentic/"; exit 1; }
      if [ -z "$L_TARGETS" ] || [ "$(norm_targets "$L_TARGETS")" = "$(norm_targets "$dt")" ]; then
        echo "$L_KEY installs to every target; no line needed"; exit 0
      fi ;;
  esac
  new_id="$(line_ident "$dt")"
  while IFS= read -r l; do
    if parse_line "$l" && [ "$(line_ident "$dt")" = "$new_id" ]; then
      if [ "$l" = "$line" ]; then echo "already there: $line"; exit 0; fi
      L="$line" yq -i ".setup[$i] = strenv(L)" "$f"
      echo "replaced: $l"; exit 0
    fi
    i=$((i + 1))
  done < <(lines)
  L="$line" yq -i '.setup = ((.setup // []) + [strenv(L)])' "$f"
  echo "added: $line"
}

cmd_remove() {
  local kind="${1:?usage: remove KIND KEY [--target T]}" key="${2:?usage: remove KIND KEY [--target T]}" want="" l i=0 hit=()
  if [ "${3:-}" = --target ]; then want="$(norm_targets "${4:-}")" || { say "--target takes claude, copilot or claude,copilot"; exit 1; }; fi
  key="${key%/}"
  local all=(); mapfile -t all < <(lines)
  for l in "${all[@]}"; do
    if parse_line "$l" && [ "$L_KIND" = "$kind" ] && [ "$L_KEY" = "$key" ]; then
      if [ -z "$want" ] || [ "$(line_ident "$dt" | cut -f3)" = "$want" ]; then hit+=("$i"); fi
    fi
    i=$((i + 1))
  done
  [ "${#hit[@]}" -gt 0 ] || { say "no $kind $key in setup:"; exit 3; }
  for ((i = ${#hit[@]} - 1; i >= 0; i--)); do
    echo "removed: ${all[${hit[i]}]}"
    yq -i "del(.setup[${hit[i]}])" "$f"
  done
}

cmd_list() {
  local l
  while IFS= read -r l; do
    if parse_line "$l"; then printf '%s\t%s\n' "$L_PHASE" "$l"; else printf 'invalid\t%s\n' "$l"; fi
  done < <(lines)
}

cmd_run_args() {
  local l
  while IFS= read -r l; do
    parse_line "$l" || continue
    case "$L_KIND" in
      mount) printf 'mount\t%s\t%s\t%s\t%s\n' "$L_SRC" "$L_DEST" "$L_OPT" "$l" ;;
      volume) printf 'volume\t%s\t%s\t\t%s\n' "$L_KEY" "$L_DEST" "$l" ;;
      workspace) [ "$L_OPT" = path ] && printf 'bind\t%s\t%s\t\t%s\n' "$L_SRC" "$L_DEST" "$l" ;;
    esac
  done < <(lines)
  return 0
}

case "${1:-}" in
  add) cmd_add "${2:?usage: add LINE}" ;;
  remove) shift; cmd_remove "$@" ;;
  list) cmd_list ;;
  run-args) cmd_run_args ;;
  *) say "usage: agentic-setup-edit [--dir D] add LINE | remove KIND KEY [--target T] | list | run-args"; exit 2 ;;
esac
```

```bash
#!/usr/bin/env bash
# Applies one build-phase setup line to the seed homes through each target harness's own CLI.
# render-dockerfile.sh writes one RUN per line, as dev. Usage:
#   agentic-apply --default-targets T LINE | --baseline | --finish
set -euo pipefail
here="$(cd "$(dirname "$(readlink -f "${BASH_SOURCE[0]}")")" && pwd)"
AGENTIC_DIR="${AGENTIC_DIR:-$(cd "$here/.." && pwd)}"
# shellcheck source=../lib/common.sh
source "$AGENTIC_DIR/lib/common.sh"
# shellcheck source=../lib/setup-line.sh
source "$AGENTIC_DIR/lib/setup-line.sh"
seed="${AGENTIC_SEED:-$AGENTIC_DIR/seed}"
t="${AGENTIC_NET_TIMEOUT:-300}"
mkdir -p "$seed/claude" "$seed/copilot"

# on HARNESS ARG...: the harness CLI on its seed home, never waiting for input.
on() {
  local h="$1"; shift
  case "$h" in
    claude) CLAUDE_CONFIG_DIR="$seed/claude" timeout "$t" claude "$@" </dev/null ;;
    copilot) COPILOT_HOME="$seed/copilot" timeout "$t" copilot "$@" </dev/null ;;
  esac
}

# env_pairs: L_ENV with a bare KEY turned into KEY=${KEY}, a reference the harness expands at run time.
env_pairs() {
  local e
  for e in "${L_ENV[@]}"; do
    # shellcheck disable=SC2016  # a literal ${KEY}, never expanded here
    if [[ "$e" == *=* ]]; then printf '%s\n' "$e"; else printf '%s=${%s}\n' "$e" "$e"; fi
  done
}

apply_claude() {
  local e args=()
  case "$L_KIND" in
    marketplace) on claude plugin marketplace add "$L_SRC" ;;
    plugin)
      if [ "${L_KEY#*@}" = claude-plugins-official ] \
         && ! jq -e 'has("claude-plugins-official")' "$seed/claude/plugins/known_marketplaces.json" >/dev/null 2>&1; then
        on claude plugin marketplace add anthropics/claude-plugins-official || return 1
      fi
      on claude plugin install -s user "$L_KEY" ;;
    mcp)
      if [ -n "$L_TRANSPORT" ]; then on claude mcp add -s user --transport "$L_TRANSPORT" "$L_KEY" "$L_URL"; return; fi
      while IFS= read -r e; do [ -z "$e" ] || args+=(-e "$e"); done < <(env_pairs)
      on claude mcp add -s user "$L_KEY" "${args[@]}" -- "${L_CMD[@]}" ;;
  esac
}

apply_copilot() {
  local e args=()
  case "$L_KIND" in
    marketplace) on copilot plugin marketplace add "$L_SRC" ;;
    plugin) on copilot plugin install "$L_KEY" ;;
    mcp)
      if [ -n "$L_TRANSPORT" ]; then on copilot mcp add --transport "$L_TRANSPORT" "$L_KEY" "$L_URL"; return; fi
      while IFS= read -r e; do [ -z "$e" ] || args+=(--env "$e"); done < <(env_pairs)
      on copilot mcp add "$L_KEY" "${args[@]}" -- "${L_CMD[@]}" ;;
  esac
}

baseline() {
  local h kind p
  on claude mcp list >/dev/null 2>&1 || true
  on copilot mcp list >/dev/null 2>&1 || true
  while IFS=$'\t' read -r h kind p; do
    case "$h" in ''|'#'*) continue ;; esac
    [ "$kind" = json ] || continue
    mkdir -p "$(dirname "$seed/.baseline/$h/$p")"
    if [ -s "$seed/$h/$p" ]; then cp "$seed/$h/$p" "$seed/.baseline/$h/$p"; else echo '{}' > "$seed/.baseline/$h/$p"; fi
  done < "$AGENTIC_DIR/lib/seed-map.tsv"
}

finish() {
  mkdir -p "$seed/.built"
  jq -c '.plugins // {} | keys' "$seed/claude/plugins/installed_plugins.json" > "$seed/.built/claude-plugins.json" 2>/dev/null \
    || echo '[]' > "$seed/.built/claude-plugins.json"
  on copilot plugin list > "$seed/.built/copilot-plugins.txt" 2>/dev/null || : > "$seed/.built/copilot-plugins.txt"
}

case "${1:-}" in
  --baseline) baseline; exit 0 ;;
  --finish) finish; exit 0 ;;
  --default-targets) dt="${2:?}"; line="${3:?usage: agentic-apply --default-targets T LINE}" ;;
  *) say "usage: agentic-apply --default-targets T LINE | --baseline | --finish"; exit 2 ;;
esac
parse_line "$line" || { say "invalid line: $L_ERR"; exit 1; }
case "$L_KIND" in marketplace|plugin|mcp) ;; *) say "$L_KIND lines are not applied at build"; exit 1 ;; esac
IFS=, read -ra targets <<<"$(norm_targets "${L_TARGETS:-$dt}")"
for h in "${targets[@]}"; do
  if ! "apply_$h"; then say "setup line failed for $h: $line"; exit 1; fi
done
```

```jq
# Seed merge (docs/specs/2026-10-14-revamp-design.md section 6.1).

# delta($base): the parts of . that differ from $base; objects are compared key by key.
def delta($base):
  if type == "object" and ($base | type) == "object" then
    . as $o
    | reduce keys[] as $k ({};
        if ($base | has($k)) | not then .[$k] = $o[$k]
        elif $o[$k] == $base[$k] then .
        else .[$k] = ($o[$k] | delta($base[$k])) end)
  else . end;

# drop($keys): . without the top-level keys in $keys.
def drop($keys): reduce $keys[] as $k (.; del(.[$k]));

# seedmerge($old; $new): the home (.) with the new seed applied. $new's values are set; values
# only $old had are removed unless the user changed them; everything else is left alone.
def seedmerge($old; $new):
  if ($new | type) == "object" and type == "object" then
    reduce ((($old | objects | keys) // []) + ($new | keys) | unique[]) as $k (.;
      ($old | if type == "object" then .[$k] else null end) as $ok
      | if ($new | has($k)) then .[$k] = (.[$k] | seedmerge($ok; $new[$k]))
        elif has($k) and .[$k] == $ok then del(.[$k])
        else . end)
  else $new end;
```

```bash
#!/usr/bin/env bash
# Brings what the build set up (the seed homes under /opt/agentic/seed) into the harness homes:
# plugin folders are linked, JSON files get a 3-way merge, so the user's own keys survive.
set -uo pipefail
source "${AGENTIC_DIR:-/opt/agentic}/lib/common.sh"
check=0; [ "${1:-}" = --check ] && check=1
seed="${AGENTIC_SEED:-$AGENTIC_DIR/seed}"
lib="$AGENTIC_DIR/lib"
[ -d "$seed" ] || exit 0
rc=0

home_of() { case "$1" in claude) claude_dir ;; copilot) copilot_dir ;; esac; }
# home_file HARNESS PATH: where a seed path lives in the home (Claude's .claude.json is special).
home_file() {
  if [ "$1/$2" = claude/.claude.json ]; then claude_json; else printf '%s/%s\n' "$(home_of "$1")" "$2"; fi
}
read_json() { if [ -s "$1" ] && jq -e . "$1" >/dev/null 2>&1; then cat "$1"; else echo '{}'; fi; }

while IFS=$'\t' read -r h kind p; do
  case "$h" in ''|'#'*) continue ;; esac
  src="$seed/$h/$p"; dst="$(home_file "$h" "$p")"
  case "$kind" in
    link)
      [ -e "$src" ] || continue
      if [ -e "$dst" ] && [ ! -L "$dst" ]; then
        if [ "$check" = 1 ]; then say "$dst is a real folder; the image's $p is not linked"; rc=2; continue; fi
        mv "$dst" "$dst.pre-seed.$(date +%s)"
        say "moved $dst aside to link the image's $p"; rc=2
      fi
      if [ "$(readlink "$dst" 2>/dev/null)" != "$src" ]; then
        if [ "$check" = 1 ]; then say "$dst is not linked to the image's $p"; rc=2
        else mkdir -p "$(dirname "$dst")"; ln -sfn "$src" "$dst"; fi
      fi ;;
    json)
      if [ -s "$dst" ] && ! jq -e . "$dst" >/dev/null 2>&1; then say "$dst is not valid JSON; left alone"; rc=2; continue; fi
      snap="$(home_of "$h")/.agentic-seed/$p"
      new="$(read_json "$src" | jq -c -L "$lib" --argjson base "$(read_json "$seed/.baseline/$h/$p")" \
               --argjson ign "$(read_json "$lib/seed-ignore.json")" --arg k "$h/$p" \
               'include "seed"; delta($base) | drop($ign[$k] // [])')" || { say "could not read the seed's $p"; rc=2; continue; }
      cur="$(read_json "$dst")"
      next="$(jq -L "$lib" --argjson o "$(read_json "$snap")" --argjson n "$new" 'include "seed"; seedmerge($o; $n)' <<<"$cur")"
      if [ "$check" = 1 ]; then
        [ "$(jq -S . <<<"$cur")" = "$(jq -S . <<<"$next")" ] || { say "$dst lacks what the setup lines set up"; rc=2; }
        continue
      fi
      write_if_changed "$dst" "$next"
      write_if_changed "$snap" "$new" ;;
  esac
done < "$lib/seed-map.tsv"
exit "$rc"
```

```bash
# marked_block FILE MARK TEXT: FILE keeps its own text; TEXT sits between two MARK lines at the end.
# An empty TEXT removes the block.
marked_block() {
  local f="$1" mark="$2" text="$3" own
  own="$(if [ -f "$f" ]; then sed "/^$mark\$/,/^$mark\$/d" "$f"; fi)"
  if [ -n "$text" ]; then write_if_changed "$f" "$(printf '%s\n%s\n%s\n%s\n' "$own" "$mark" "$text" "$mark" | sed '/./,$!d')"
  elif [ -f "$f" ]; then write_if_changed "$f" "$own"; fi
}
```

```bash
# agentic.run label written by agentic build), appended to RUN_ARGS. ~ is the host home; a relative
```

```bash
#!/usr/bin/env bash
# The setup-line commands of the host CLI: add, copy, mount, volume, remove, list. The file is edited
# by agentic-setup-edit in a throwaway container (the host has no yq). Source, do not execute.

# setup_edit ARG...: agentic-setup-edit on this project's .agentic/.
setup_edit() {
  local img; img="$(base_image_of)"
  image_exists "$img" || die "$img not found; run agentic build-base (or pull your overlay) first"
  docker run --rm --user "$(id -u):$(id -g)" -v "$(cfg_dir):/agentic-config" \
    --entrypoint /opt/agentic/bin/agentic-setup-edit "$img" "$@"
}

# localise KIND PATH: PATH as a path inside .agentic/, copied to .agentic/KIND/ when it is outside.
localise() {
  local kind="$1" src="$2" cfg base
  cfg="$(cfg_dir)"
  [ -e "$src" ] || die "$src does not exist"
  src="$(realpath -- "$src")"
  case "$src/" in "$cfg/"?*) printf '%s\n' "${src#"$cfg"/}"; return 0 ;; esac
  base="$(basename "$src")"
  if [ -e "$cfg/$kind/$base" ]; then
    diff -rq -- "$src" "$cfg/$kind/$base" >/dev/null 2>&1 || die ".agentic/$kind/$base exists and differs; rename one of them"
  else
    mkdir -p "$cfg/$kind"; cp -R -- "$src" "$cfg/$kind/$base"
  fi
  printf '%s/%s\n' "$kind" "$base"
}

# host_path PATH: a mount source as it is written in the file: ~/... under the home, relative under
# the project root, otherwise absolute. The shell has usually expanded ~ already.
host_path() {
  local p root; root="$(project_root)"
  p="$(realpath -m -- "$1")"
  case "$p/" in
    "$root/"?*) printf '%s\n' "${p#"$root"/}" ;;
    "$HOME/"?*) printf '~/%s\n' "${p#"$HOME"/}" ;;
    *) printf '%s\n' "$p" ;;
  esac
}

# line_of WORD...: the words as one setup line, single-quoting a word only when it needs it.
line_of() {
  local w out=""
  for w in "$@"; do
    if [[ "$w" =~ ^[A-Za-z0-9_@%+=:,./~-]+$ ]]; then out+="${out:+ }$w"
    else out+="${out:+ }'${w//\'/\'\\\'\'}'"; fi
  done
  printf '%s\n' "$out"
}

# split_flags ARG...: WORDS without --no-build and --yes (before --), BUILD and YES set from them.
split_flags() {
  local a after=0
  WORDS=(); BUILD=1; YES=0
  for a in "$@"; do
    if [ "$after" = 0 ]; then
      case "$a" in --no-build) BUILD=0; continue ;; --yes) YES=1; continue ;; --) after=1 ;; esac
    fi
    WORDS+=("$a")
  done
}

# after_change BUILD YES: build, then offer to recreate a running dev container (without attaching).
after_change() {
  local name ans=n
  if [ "$1" = 0 ]; then echo "not built (--no-build); run agentic build"; return 0; fi
  cmd_build
  name="agentic-$(project_name)-dev"
  [ "$(docker inspect -f '{{.State.Running}}' "$name" 2>/dev/null || true)" = true ] || return 0
  if [ "$2" = 1 ]; then ans=y
  elif [ -t 0 ]; then read -rp "recreate the running dev container $name now? It ends its tmux sessions. [y/N] " ans || ans=n; fi
  case "$ans" in
    y|Y) docker rm -f "$name" >/dev/null 2>&1 || true; dev_start "$name" "$(project_image)" 0; echo "recreated $name; attach with agentic dev" ;;
    *) echo "run agentic dev recreate to use it" ;;
  esac
}

# cmd_setup_line add ...|copy ...|mount ...|volume ...
cmd_setup_line() {
  need_config
  split_flags "$@"
  case "${WORDS[0]:-} ${WORDS[1]:-}" in
    "copy "*) WORDS[1]="$(localise files "${WORDS[1]:?usage: agentic copy SRC DEST}")" ;;
    "mount "*) WORDS[1]="$(host_path "${WORDS[1]:?usage: agentic mount SRC DEST}")" ;;
    "add skill"|"add agent"|"add command") WORDS[2]="$(localise "${WORDS[1]}s" "${WORDS[2]:?usage: agentic add ${WORDS[1]} PATH}")" ;;
    "add workspace") case "${WORDS[2]:-}" in https://*|ssh://*|git@*:*|"") ;; *) WORDS[2]="$(host_path "${WORDS[2]}")" ;; esac ;;
  esac
  setup_edit add "$(line_of "${WORDS[@]}")"
  after_change "$BUILD" "$YES"
}

# cmd_remove KIND KEY [--target T]: deletes the lines, then the asset or copied file they owned.
cmd_remove() {
  need_config
  split_flags "$@"
  local kind="${WORDS[0]:?usage: agentic remove KIND KEY [--target T]}" key="${WORDS[1]:?usage: agentic remove KIND KEY}" out rc=0 cfg
  cfg="$(cfg_dir)"
  out="$(setup_edit remove "${WORDS[@]}")" || rc=$?
  [ -z "$out" ] || printf '%s\n' "$out"
  case "$kind" in
    skill|agent|command)
      [ "$rc" = 0 ] || [ "$rc" = 3 ] || exit "$rc"
      [ -e "$cfg/${key%/}" ] && rm -rf -- "${cfg:?}/${key%/}" && echo "deleted .agentic/${key%/}" ;;
    *) [ "$rc" = 0 ] || exit "$rc" ;;
  esac
  case "$kind" in
    workspace) echo "the clone stays in $(realpath -m -- "$AGENTIC_WORKSPACES")/$(project_name)/repos/$key; delete it yourself when you are done" ;;
    volume) echo "the Docker volume agentic-$(project_name)-$key stays; docker volume rm agentic-$(project_name)-$key deletes it" ;;
    copy) echo "files under .agentic/files/ stay; delete the one you no longer need" ;;
  esac
  after_change "$BUILD" "$YES"
}

cmd_list() { need_config; setup_edit list; }
```

```bash
  parse_line "$l" || { err "$l: $L_ERR"; continue; }
  case "$L_KIND" in
    mount|volume)
      if awk -v d="$L_DEST" '$5 == d {f = 1} END {exit !f}' "$mi" 2>/dev/null; then ok "$l"
      else warn "$l: not mounted (started without the agentic CLI?)"; fi ;;
  esac
done < <(jq -r '.setup // [] | .[]' "$RESOLVED")
while IFS=$'\t' read -r server var; do
  [ -n "$server" ] || continue
  if [ -z "${!var:-}" ]; then warn "mcp $server uses \${$var}, which is not set (add it to .agentic/.env)"; fi
done < <(cat "$(claude_json)" "$(copilot_dir)/mcp-config.json" 2>/dev/null | jq -r '
  .mcpServers // {} | to_entries[] | .key as $k
  | [(.value.env // {}), (.value.headers // {})][] | .[]
  | strings | scan("\\$\\{([A-Za-z_][A-Za-z0-9_]*)\\}")[] | [$k, .] | @tsv' | sort -u)
seed="${AGENTIC_SEED:-$AGENTIC_DIR/seed}"
if [ -f "$seed/.built/claude-plugins.json" ]; then
  while IFS= read -r p; do
    warn "plugin $p was installed by hand and is gone after a recreate; keep it with: agentic add plugin $p --target claude"
  done < <(jq -r --slurpfile b "$seed/.built/claude-plugins.json" '.plugins // {} | keys - $b[0] | .[]' "$(claude_dir)/plugins/installed_plugins.json" 2>/dev/null)
fi
```
